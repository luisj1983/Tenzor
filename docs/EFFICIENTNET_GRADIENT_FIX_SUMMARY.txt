EfficientNet Gradient Chain Break - Root Cause Analysis Summary
================================================================================

EXECUTIVE SUMMARY
================================================================================
The gradient chain breaks in EfficientNet models because the Swish activation
function (and several others) are implemented incorrectly in:

  File: /home/lee/Projects/Tenzor/src/nn/activations/activations.cpp
  Lines: 344-348 (PRIMARY ISSUE - Swish)

The problem is a single line that orphans Variables from the computation graph:

  BROKEN:  return Variable(result, input.requires_grad());
  CORRECT: output.set_grad_fn(grad_fn); return output;

================================================================================
CRITICAL ROOT CAUSE
================================================================================

File: /home/lee/Projects/Tenzor/src/nn/activations/activations.cpp
Lines: 344-348

BROKEN CODE:
    auto swish(const Variable& input) -> Variable {
        std::vector<Tensor> inputs = {input.tensor()};
        auto result = Dispatcher::dispatch("swish", inputs)[0];
        return Variable(result, input.requires_grad());  // ❌ BREAKS GRADIENTS
    }

WHY IT BREAKS:
1. input.tensor() extracts the raw Tensor (loses gradient info)
2. Dispatcher::dispatch() returns a Tensor with no grad_fn
3. Variable(result, true) creates a Variable with:
   - requires_grad = true (copied from input)
   - grad_fn = nullptr (ORPHANED - NO GRADIENT FUNCTION)
4. Backprop cannot find a path through this Variable
5. Input gradients remain empty (None)

The same issue exists in 4 other functions:
  - Line 327: ELU (requires fixing)
  - Line 337: SELU (requires fixing)
  - Line 347: Mish (requires fixing)
  - Line 154: Sigmoid (BUT IS ACTUALLY CORRECT - uses full autograd setup)

================================================================================
IMPACT ON EFFICIENTNET
================================================================================

EfficientNet heavily uses Swish activation:
  1. Stem layer: 1x Swish
  2. Each MBConv block (16 total): 2-3x Swish per block = 32-48x
  3. Head layer: 1x Swish
  TOTAL: 34-50 Swish activations per forward pass

Result: Gradient chain is completely severed, preventing any gradient flow.

================================================================================
COMPARISON: BROKEN vs CORRECT PATTERN
================================================================================

BROKEN (Lines 344-348):
    auto swish(const Variable& input) -> Variable {
        std::vector<Tensor> inputs = {input.tensor()};
        auto result = Dispatcher::dispatch("swish", inputs)[0];
        return Variable(result, input.requires_grad());  // ❌
    }
    Flow: Variable → extract tensor → dispatch → NEW Variable (orphaned)

CORRECT (See lines 194-223 for sigmoid() or lines 160-192 for relu()):
    auto swish(const Variable& input) -> Variable {
        if (!input.requires_grad() || !is_grad_enabled()) {
            std::vector<Tensor> inputs = {input.tensor()};
            auto result = Dispatcher::dispatch("swish", inputs)[0];
            return Variable(result, false);  // ✓ Correct for non-grad path
        }

        // Compute forward
        std::vector<Tensor> inputs_vec = {input.tensor()};
        auto result_tensor = Dispatcher::dispatch("swish", inputs_vec)[0];

        // Create backward function and set up computation graph
        auto grad_fn = std::make_shared<SwishBackward>();  // ✓ NEW
        grad_fn->save_for_backward({input.tensor(), result_tensor});  // ✓ NEW

        std::vector<std::shared_ptr<Function>> next_funcs;
        if (input.grad_fn()) {
            next_funcs.push_back(input.grad_fn());  // ✓ NEW
        }
        grad_fn->set_next_functions(next_funcs);  // ✓ NEW

        std::vector<Variable> input_vars;
        input_vars.push_back(input);
        grad_fn->set_input_variables(input_vars);  // ✓ NEW

        Variable output(result_tensor, true);
        output.set_grad_fn(grad_fn);  // ✓ CRITICAL - ATTACH GRADIENT FUNCTION
        return output;
    }
    Flow: Variable → extract tensor → dispatch → NEW Variable → set grad_fn → return (connected!)
