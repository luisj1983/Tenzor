Detailed Description

Generate anchor boxes at multiple scales and aspect ratios.

Creates anchor boxes for each position in a feature map. Anchors are defined by their size (scale) and aspect ratio (width/height).

Example:

AnchorGenerator anchors({32.0f, 64.0f, 128.0f}, {0.5f, 1.0f, 2.0f});
auto boxes = anchors.generate(38, 38, 16); // 38x38 feature map, stride 16
// Returns: (38*38*9, 4) tensor with (x1, y1, x2, y2) coordinates

Generate anchors for a feature map.

Creates anchors at each spatial position of the feature map. The number of anchors per location equals sizes.size() * aspect_ratios.size().

Parameters

feat_widthFeature map width
strideFeature map stride relative to input image (e.g., 16 for 1/16 resolution)
deviceDevice to create anchors on (default: CPU)
Returns
Tensor of shape (H*W*K, 4) where K=num_anchors_per_location Format: (x1, y1, x2, y2) in image coordinates
