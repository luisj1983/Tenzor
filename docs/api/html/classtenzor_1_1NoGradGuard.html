Detailed Description

RAII guard for temporarily disabling gradient computation.

Creates a context where gradient computation is disabled. Restores previous state when destroyed. Useful for inference or when computing values that shouldn't be part of the gradient graph.

Variable x(tensor, true);
{
NoGradGuard guard;
Variable y = x * 2.0f; // No gradient tracking
// y.backward() would fail
}
Variable z = x * 3.0f; // Gradient tracking restored
