Detailed Description

Common subexpression elimination pass.

Detects and merges duplicate computations. If two nodes have:

  • Same operation type
  • Same inputs
  • Same attributes Then they can be merged into one.

Example:

a = relu(x)
b = relu(x) # Duplicate - can reuse 'a'
c = a + b # Becomes: c = a + a
