Detailed Description

Learnable fake quantization with trainable parameters.

Extends fake quantization with learnable scale and zero_point parameters that are optimized during training for optimal quantization.

auto learnable_fq = std::make_shared<LearnableFakeQuantize>();
learnable_fq->train();
// During training, scale and zero_point are updated via gradients
Variable output = learnable_fq->forward(input);
loss.backward();
optimizer.step(); // Updates scale and zero_point
