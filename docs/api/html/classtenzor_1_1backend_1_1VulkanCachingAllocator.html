Detailed Description

VulkanCachingAllocator for efficient Vulkan GPU memory management.

Implements a memory pooling system that reuses freed memory blocks to reduce vkAllocateMemory/vkFreeMemory overhead. Uses best-fit allocation strategy with block splitting to reduce fragmentation.

Thread-safe and supports multiple Vulkan devices.
