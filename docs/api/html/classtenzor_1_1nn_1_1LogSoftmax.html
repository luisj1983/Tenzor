Detailed Description

Log-Softmax activation function.

Applies log(softmax(x)) in numerically stable way:

Preferred over Softmax + Log for numerical stability and efficiency. Commonly used with NLLLoss for classification.

Parameters
dimDimension along which to apply log-softmax (default: -1)
Complexity
  • Time: O(n)
  • Space: O(1)
auto log_softmax = LogSoftmax(-1);
auto log_probs = log_softmax.forward(logits);
auto loss = nll_loss(log_probs, targets); // Efficient combination
