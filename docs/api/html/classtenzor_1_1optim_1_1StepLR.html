Detailed Description

Step learning rate scheduler.

Multiplies learning rate by gamma every step_size epochs:

where:

  • : initial learning rate
  • : multiplicative factor (default: 0.1)
  • : step size in epochs
  • : current epoch

Use Cases:

  • Most common LR schedule
  • Simple and effective
  • Good default choice

Typical Configuration:

  • step_size: 30-50 epochs
  • gamma: 0.1 (reduce LR by 10x)
Parameters
optimizerOptimizer to schedule (SGD, Adam, or AdamW)
step_sizePeriod of learning rate decay in epochs
gammaMultiplicative factor of learning rate decay (default: 0.1)
auto scheduler = StepLR(optimizer, 30, 0.1);
// LR = initial_lr at epochs 0-29
// LR = initial_lr * 0.1 at epochs 30-59
// LR = initial_lr * 0.01 at epochs 60-89
