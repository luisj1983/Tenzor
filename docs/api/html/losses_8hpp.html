Detailed Description

Loss functions for neural network training.

This file provides common loss (cost/objective) functions used in supervised learning. Loss functions measure the difference between predictions and targets, providing the signal for backpropagation and optimization.

enum class tenzor::nn::Reduction
strong

Reduction mode for loss functions.

Specifies how to aggregate individual element losses into a single scalar value.

  • None: Return loss for each element (no reduction)
  • Mean: Average loss across all elements (default for most losses)
  • Sum: Sum all individual losses

Choosing Reduction:

  • Mean: Use when batch size varies (normalizes by count)
  • Sum: Use when you want gradient scale independent of batch size
  • None: Use for custom per-element processing
Enumerator
None 

No reduction, return per-element loss.

Mean 

Average reduction (divide by number of elements).

Sum 

Sum reduction (sum all losses).
