Detailed Description

Graph optimization passes for JIT compilation.

Provides a suite of optimization passes that transform IR graphs for improved performance. Includes:

  • Operator fusion (Conv+BatchNorm, Conv+ReLU, etc.)
  • Dead code elimination (DCE)
  • Common subexpression elimination (CSE)
  • Constant folding
  • Algebraic simplification
