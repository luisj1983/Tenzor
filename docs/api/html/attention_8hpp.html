Helper function to create causal attention mask.

Creates a triangular mask that prevents attending to future positions. Used for autoregressive models (e.g., GPT, language modeling).

The mask is upper triangular with -inf above the diagonal:

[[ 0, -inf, -inf],
[ 0, 0, -inf],
[ 0, 0, 0]]
Parameters
seq_lenSequence length
deviceDevice to create mask on
Returns
Causal mask tensor of shape (seq_len, seq_len)

auto [output, _] = attn.forward(x, x, x, Tensor{}, mask);
