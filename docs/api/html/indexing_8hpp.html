◆ nonzero()

auto tenzor::nonzero ( const Tensor & input) ->Tensor

Return indices of non-zero elements.

Returns a 2D tensor where each row contains the indices of a non-zero element. For a 1D tensor, returns indices as a (N, 1) tensor. For a multi-dimensional tensor, each row is [dim0_idx, dim1_idx, ...].

Parameters
inputInput tensor
Returns
Tensor of indices (num_nonzero, ndim) in Int64 format

int64_t start,

Slice variable along dimension with gradient tracking.

Extracts a slice from the input variable along the specified dimension. Gradients are scattered back to original positions during backpropagation.

Parameters
inputInput variable to slice
dimDimension along which to slice
startStart index (inclusive)
endEnd index (exclusive)
stepStep size (default: 1)
Returns
Variable containing sliced tensor with gradient function
Variable x(Tensor({10, 20}, DType::Float32, Device::cpu()), true);
Variable y = slice(x, 1, 5, 15, 2); // Shape: {10, 5} - every 2nd element from index 5 to 15
// Backward: gradient scattered back to positions [5, 7, 9, 11, 13] in dimension 1
See also
SliceBackward for gradient implementation
