Detailed Description

Abstract base class for device backend implementations.

Defines the interface that all backend implementations must provide, including memory management, kernel dispatch, and synchronization.

Concrete backends (CPUBackend, CUDABackend, etc.) inherit from this class and implement all virtual methods for their specific hardware.

Note
This class uses the Strategy pattern for polymorphic dispatch.
See also
BackendLoader for dynamic backend loading
