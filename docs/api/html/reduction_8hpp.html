Detailed Description

Tensor reduction operations.

Provides operations that reduce tensors along specified dimensions, including sum, mean, min, max, and statistical operations.

auto tenzor::max ( const Variable & input,
std::optional< int64_t > dim = std::nullopt,
bool keepdim = false )->Variable

Max reduction with gradient tracking.

Computes maximum of tensor elements along specified dimension. Gradients flow only to maximum elements during backpropagation.

Parameters
inputInput variable
dimOptional dimension to reduce (nullopt = all dimensions)
keepdimIf true, keep reduced dimension with size 1
Returns
Variable containing max values with gradient function
Note
If multiple elements are tied for max, gradient is distributed.

Sum reduction with gradient tracking.

Computes sum of tensor elements along specified dimension. Gradients are broadcast back to original shape during backpropagation.

Parameters
inputInput variable
dimOptional dimension to reduce (nullopt = all dimensions)
keepdimIf true, keep reduced dimension with size 1
Returns
Variable containing sum with gradient function
Variable x(Tensor({3, 4}, DType::Float32, Device::cpu()), true);
Variable row_sums = sum(x, 1); // Shape: {3}
Variable col_sums = sum(x, 0, true); // Shape: {1, 4}
Variable total = sum(x); // Shape: {}
