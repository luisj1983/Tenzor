Detailed Description

Standard dropout layer.

During training, randomly zeros elements with probability p using samples from a Bernoulli distribution. Remaining elements are scaled by 1/(1-p). During evaluation, performs identity operation (no dropout).

Dropout is a regularization technique that prevents co-adaptation of neurons and reduces overfitting.

Shape:

  • Input: Any shape
  • Output: Same as input
Dropout dropout(0.5); // Drop 50% of elements
Variable x(Tensor({batch, 512}, DType::Float32, Device::cpu()), true);
Variable dropped = dropout.forward(x); // Training mode
dropout.eval(); // Switch to evaluation mode
Variable kept = dropout.forward(x); // No dropout applied
