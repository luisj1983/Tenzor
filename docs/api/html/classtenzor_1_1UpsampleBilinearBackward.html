Detailed Description

Bilinear upsample gradient function.

Implements forward and backward for bilinear upsampling (currently using nearest neighbor).

Forward: y = upsample(x, target_h, target_w) Backward: Distribute dL/dy back to input pixels

For nearest neighbor upsampling:

  • Each output pixel comes from exactly one input pixel
  • Gradient at output pixel is added back to corresponding input pixel
Note
Current implementation uses nearest neighbor for both forward and backward. True bilinear interpolation would distribute gradients to 4 neighboring pixels.
