Detailed Description

Specialized layers for semantic segmentation.

Implements segmentation-specific layers including Atrous Spatial Pyramid Pooling (ASPP), Atrous Separable Convolution, and other components for semantic segmentation models like DeepLab v3+.

Bilinear upsampling helper function.

Performs bilinear interpolation to upsample feature maps to target size. This is a temporary implementation until a full interpolate operation is added to Tenzor core.

Parameters
inputInput tensor of shape (N, C, H_in, W_in)
target_hTarget height
target_wTarget width
Returns
Upsampled tensor of shape (N, C, target_h, target_w)
Note
This is implemented using nearest neighbor for now. Full bilinear interpolation should be implemented in core ops.
