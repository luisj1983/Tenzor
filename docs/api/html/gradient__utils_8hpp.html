auto tenzor::optim::compute_bucket_sizes ( const std::vector< Tensor > & tensors,
const BucketConfig & config = BucketConfig{} )->std::vector< BucketInfo >

Compute optimal bucket sizes for gradient communication.

Divides parameters into buckets for efficient collective communication operations. Tries to balance:

  • Bucket size (should be large enough to amortize communication overhead)
  • Number of buckets (more buckets = more parallelism)
  • Alignment (avoid splitting parameters across buckets if possible)

Algorithm:

  1. Calculate total gradient memory
  2. Determine number of buckets based on max_bucket_size
  3. Assign parameters to buckets greedily
  4. Ensure all parameters have the same dtype per bucket
Parameters
tensorsVector of tensors to bucket (typically parameters)
configBucketing configuration
Returns
Vector of bucket information structures
Exceptions
std::invalid_argumentif input is empty
BucketConfig config;
config.max_bucket_size_mb = 25; // 25MB buckets
auto buckets = compute_bucket_sizes(model.parameters(), config);
std::cout << "Created " << buckets.size() << " buckets\n";

auto tenzor::optim::flatten_tensors ( const std::vector< Tensor > & tensors) ->Tensor

Flatten a vector of tensors into a single contiguous tensor.

Combines multiple tensors with potentially different shapes into a single 1D tensor by concatenating their data in memory order.

All input tensors must:

  • Have the same dtype
  • Be on the same device
  • Be contiguous in memory (call .contiguous() if needed)
Parameters
tensorsVector of tensors to flatten
Returns
Single 1D tensor containing all data from input tensors
Exceptions
std::invalid_argumentif tensors have different dtypes or devices
std::invalid_argumentif input is empty
std::vector<Tensor> grads = {
Tensor({10, 20}, DType::Float32, Device::cpu()),
Tensor({5, 5}, DType::Float32, Device::cpu())
};
Tensor flat = flatten_tensors(grads); // Shape: {225} (200 + 25)

auto tenzor::optim::unflatten_into ( const Tensor & flat_tensor,
const std::vector< std::vector< int64_t > > & shapes )->std::vector< Tensor >

Unflatten a contiguous tensor back into a vector of tensors.

Splits a flattened 1D tensor back into multiple tensors with specified shapes. This is the inverse operation of flatten_tensors().

The sum of elements in shapes must equal the number of elements in the input tensor.

Parameters
flat_tensorFlattened 1D tensor
shapesVector of shapes for output tensors
Returns
Vector of tensors with specified shapes
Exceptions
std::invalid_argumentif shapes don't match flat_tensor size
std::invalid_argumentif flat_tensor is not 1D
Tensor flat = Tensor({225}, DType::Float32, Device::cpu());
std::vector<std::vector<int64_t>> shapes = {{10, 20}, {5, 5}};
auto tensors = unflatten_into(flat, shapes); // 2 tensors: {10,20} and {5,5}

auto tenzor::optim::unflatten_into ( const Tensor & flat_tensor,
std::vector< Tensor > & output_tensors )->void

Unflatten a tensor and copy into existing tensor views.

Splits a flattened tensor and copies data into provided output tensors. Output tensors must already be allocated with correct shapes and dtypes.

This is more efficient than unflatten_into() when output tensors are already allocated, as it avoids creating new tensors.

Parameters
flat_tensorFlattened 1D tensor
output_tensorsPre-allocated output tensors to copy into
Exceptions
std::invalid_argumentif output tensors don't match flat_tensor size
std::invalid_argumentif dtypes don't match
Tensor flat = flatten_tensors(gradients);
// ... communicate flat tensor ...
unflatten_into(flat, gradients); // Copy back into original gradients
