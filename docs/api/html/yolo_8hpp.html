Detailed Description

YOLO (You Only Look Once) single-stage object detection models.

Implements YOLOv3 and YOLOv5 architectures for real-time object detection. YOLOv3: Darknet53 backbone with multi-scale predictions YOLOv5: CSPDarknet backbone with PANet and improved training

References:

  • YOLOv3: "YOLOv3: An Incremental Improvement" (Redmon & Farhadi, 2018)
  • YOLOv5: https://github.com/ultralytics/yolov5
