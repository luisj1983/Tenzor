Detailed Description

ROI Head for object detection (classification and box regression).

Implements the second stage of two-stage detectors like Faster R-CNN and Mask R-CNN. Takes region proposals and performs:

  1. ROI feature extraction (ROI Align/Pooling)
  2. Box classification (C classes + background)
  3. Box regression refinement
