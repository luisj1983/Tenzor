Detailed Description

Swin Transformer hierarchical vision transformer.

Implements the complete Swin Transformer family with shifted window multi-head self-attention for efficient hierarchical feature learning.

Reference: "Swin Transformer: Hierarchical Vision Transformer using Shifted Windows" (Liu et al., ICCV 2021 Best Paper)
