Detailed Description

Process group for distributed training.

Manages communication backend, process ranks, and provides high-level collective operation APIs. Thread-safe and supports multiple devices.

Usage:

auto pg = ProcessGroup::create_process_group(Backend::NCCL, 0, 4);
Tensor data = torch::randn({10, 10}, Device::cuda(0));
pg->all_reduce(data, ReduceOp::SUM);
