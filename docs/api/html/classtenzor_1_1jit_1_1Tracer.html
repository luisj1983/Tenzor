Detailed Description

Tracing context that records operations during execution.

The Tracer maintains a global state while tracing is active, recording all operations performed on tensors and variables. It builds a complete IR graph that can be optimized and serialized.

Thread-local storage ensures thread safety for multi-threaded tracing.

Tracer tracer;
tracer.start_trace();
// Operations are automatically recorded
Variable output = model(input);
auto graph = tracer.end_trace({input}, {output});
