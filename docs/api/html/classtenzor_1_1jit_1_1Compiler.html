Detailed Description

Compiler that applies optimization passes.

The compiler runs a sequence of passes to transform and optimize the IR graph. Passes are applied in order until convergence or max iterations is reached.

Compiler compiler;
compiler.add_pass(std::make_unique<DeadCodeEliminationPass>());
compiler.add_pass(std::make_unique<FuseConvBatchNormPass>());
compiler.add_pass(std::make_unique<FuseConvReluPass>());
compiler.optimize(graph);
