Detailed Description

Moving average min-max observer.

Similar to MinMaxObserver but uses exponential moving average to reduce sensitivity to outliers and adapt to changing distributions.

Update rule: min_avg = momentum * min_avg + (1 - momentum) * current_min max_avg = momentum * max_avg + (1 - momentum) * current_max

MovingAverageMinMaxObserver observer(0.99); // Heavy smoothing
