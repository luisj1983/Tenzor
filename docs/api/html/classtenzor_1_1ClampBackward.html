Detailed Description

Clamp gradient function.

Forward: y = clamp(x, min, max) = max(min, min(x, max)) Backward: dL/dx = dL/dy * (min < x < max)

Note
Gradient passes through only for elements within bounds. Input is saved.
Variable x(Tensor({3, 4}, DType::Float32, Device::cpu()), true);
Variable y = clamp(x, -1.0f, 1.0f); // Clamp to [-1, 1]
