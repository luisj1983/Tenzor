Detailed Description

Adam-atan2 optimizer from the HRM paper.

Implements Adam with atan2-based update rule for bounded gradient steps. This provides more stable training by naturally bounding the update magnitude.

Reference: "Hierarchical Reasoning Model" (Wang et al., 2025)
