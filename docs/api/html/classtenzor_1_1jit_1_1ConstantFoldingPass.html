Detailed Description

Constant folding pass.

Evaluates operations on constant inputs at compile time. Replaces the operation with a constant node.

Example:

a = Constant(2.0)
b = Constant(3.0)
c = a + b # Can be folded to Constant(5.0)
d = c * x # Becomes: Constant(5.0) * x
