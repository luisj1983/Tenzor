Detailed Description

Utility class for ROI Align operations.

Provides static methods for ROI Align computation with bilinear interpolation. This is a pure utility class (not an autograd::Function). The ROIAlign module class handles autograd integration through its own backward function.

Design Note: Named "Op" instead of "Function" to avoid confusion with autograd::Function base class and prevent any virtual function hiding concerns.
