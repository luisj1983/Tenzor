Detailed Description

Computation graph for automatic differentiation.

Manages the directed acyclic graph (DAG) of operations performed during the forward pass. This graph is used during backpropagation to compute gradients in the correct order.

Key features:

  • Dynamic graph construction during forward pass
  • Topological sorting for backward pass
  • Efficient memory management with reference counting
  • Graph statistics and analysis

The graph is typically managed automatically by Variable and BackwardEngine rather than being used directly.

ComputationGraph graph;
// Add operations to graph
auto node1 = graph.add_node(add_func);
auto node2 = graph.add_node(mul_func);
// Connect operations
graph.connect(node1, node2);
// Get execution order for backward pass
auto sorted = graph.topological_sort(node2);
// Clean up
graph.clear();

auto tenzor::ComputationGraph::topological_sort ( std::shared_ptr< GraphNode > root) ->std::vector< std::shared_ptr< GraphNode > >

Perform topological sort from root node.

Computes a topologically sorted order of nodes from the root backward to all dependencies. This order ensures that gradients are computed correctly during backpropagation.

Uses depth-first search with cycle detection to traverse the graph.

Parameters

Returns
