Detailed Description

Subtraction gradient function.

Implements forward and backward for element-wise subtraction with broadcasting support.

Forward: C = A - B (with broadcasting) Backward: dL/dA = sum_reduce(dL/dC), dL/dB = -sum_reduce(dL/dC)

Note
Gradients are sum-reduced along broadcasted dimensions to match input shapes.
