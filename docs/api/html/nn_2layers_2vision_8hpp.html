Create attention mask for shifted window attention.

Creates a mask that prevents attention between non-adjacent regions after applying cyclic shift. This is used for SW-MSA in Swin Transformer.

Parameters
HHeight of feature map
WWidth of feature map
window_sizeWindow size M
shift_sizeShift size (typically M/2)
deviceDevice to create mask on
Returns
Attention mask of shape (num_windows, M*M, M*M) Masked positions have value -100.0
Tensor mask = create_shifted_window_mask(56, 56, 7, 3);
// Result: shape (64, 49, 49) with -100.0 for masked positions

auto tenzor::nn::window_partition ( const Variable & input,
int64_t window_size )->Variable

Helper function to partition tensor into windows.

Splits the input feature map into non-overlapping M×M windows.

Parameters
inputInput tensor of shape (B, H, W, C)
window_sizeWindow size M
Returns
Windowed tensor of shape (B*num_windows, M*M, C) where num_windows = (H/M) * (W/M)
Exceptions
std::invalid_argumentif H or W not divisible by window_size
Variable features({batch, 56, 56, 96});
Variable windows = window_partition(features, 7);
// Result: shape (batch*64, 49, 96) since 56/7=8, 8*8=64 windows
