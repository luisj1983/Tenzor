Detailed Description

Layer Scale module for training stability.

Layer Scale applies learnable per-channel scaling factors. Initialized to a small value (1e-6) to improve training stability, especially for deeper models.

Formula: output = gamma * input where gamma is learnable and initialized to init_value.

Reference: "Going deeper with Image Transformers" (Touvron et al., 2021)
