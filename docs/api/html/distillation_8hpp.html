Detailed Description

Knowledge distillation for model compression and transfer learning.

Implements knowledge distillation techniques where a smaller "student" model learns to mimic a larger "teacher" model. Uses soft targets and temperature scaling to transfer knowledge more effectively than training on hard labels alone.

  1. Soft target loss: KL divergence between student and teacher
  2. Hard target loss: Cross-entropy with true labels

Feature-based distillation loss.

Matches intermediate feature representations between teacher and student. Often more effective than output distillation for vision tasks.

Algorithm:

  1. Extract features from teacher layer
  2. Extract features from student layer (may need projection)
  3. Compute similarity loss (MSE, cosine, attention transfer)

Common Approaches:

  • FitNets: MSE between feature maps
  • Attention Transfer: Matching attention maps
  • FSP: Flow of Solution Procedure
Parameters
student_featuresStudent intermediate features
teacher_featuresTeacher intermediate features
loss_typeType of feature matching ("mse", "cosine", "attention")
Returns
Feature distillation loss
// Extract features from specific layers
Variable student_feat = student->get_layer("conv4")->output;
Variable teacher_feat = teacher->get_layer("conv4")->output;
Variable feat_loss = feature_distillation_loss(student_feat, teacher_feat, "mse");

Self-distillation loss (student learns from itself).

Uses model's own predictions as soft targets. Surprisingly effective for regularization and ensemble-like behavior.

Approaches:

  • Temporal ensemble: Average predictions over time
  • Deep supervision: Early layers learn from final layer
  • Label smoothing: Soften one-hot labels
Parameters

Returns

auto tenzor::nn::compression::temperature_softmax ( const Variable & logits,
float temperature,
int64_t dim = -1 )->Variable

Temperature-scaled softmax.

Applies softmax with temperature scaling:

Effect of Temperature:

  • T → 0: Approaches one-hot (argmax)
  • T = 1: Standard softmax
  • T → ∞: Approaches uniform distribution

Higher temperature reveals relative confidences between classes, providing richer learning signal for student.

Parameters
logitsRaw model outputs (before softmax)
temperatureTemperature parameter T > 0
dimDimension to apply softmax (default: -1)
Returns
Temperature-scaled probabilities
Variable logits = model->forward(input);
Variable soft_probs = temperature_softmax(logits, 5.0f);
