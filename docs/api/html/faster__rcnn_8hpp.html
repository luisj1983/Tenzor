Detailed Description

Faster R-CNN object detection model.

Implements Faster R-CNN, a two-stage object detector that achieves state-of-the-art accuracy by combining:

  1. Region Proposal Network (RPN) for generating proposals
  2. ROI Head for classifying and refining proposals

Reference: "Faster R-CNN: Towards Real-Time Object Detection with Region Proposal Networks" (Ren et al., NIPS 2015)

Architecture:

Input Image
↓
Backbone (ResNet-50/101) → Feature Maps
↓
├─→ RPN → Proposals
└─→ ROI Head (with proposals) → Detections
