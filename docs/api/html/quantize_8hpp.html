Detailed Description

Quantization operations and schemes for neural network inference.

Provides quantization operations for converting floating-point tensors to lower-precision integer representations (INT8, UINT8) for efficient inference. Supports per-tensor and per-channel quantization with symmetric and asymmetric modes.
