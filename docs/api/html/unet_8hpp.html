Detailed Description

U-Net architecture for semantic segmentation.

Implements the U-Net encoder-decoder architecture with skip connections for biomedical image segmentation and general semantic segmentation tasks.

Reference: Ronneberger et al. "U-Net: Convolutional Networks for Biomedical Image Segmentation" (MICCAI 2015)
