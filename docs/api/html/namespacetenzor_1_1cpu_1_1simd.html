float * out,

Vectorized GELU: out[i] = a[i] * Phi(a[i]).

where Phi(x) is the cumulative distribution function of the standard normal distribution. Uses approximation: GELU(x) ≈ 0.5 * x * (1 + tanh(sqrt(2/π) * (x + 0.044715 * x^3)))
