Asynchronous 2D convolution.

Performs 2D convolution without blocking. Particularly beneficial for GPU operations where multiple convolutions can overlap.

Parameters
inputInput tensor (N, C_in, H, W)
weightConvolution kernel (C_out, C_in/groups, K, K)
biasOptional bias (C_out)
strideConvolution stride
paddingZero padding
dilationKernel dilation
groupsNumber of groups
Returns
Future<Tensor> for output (N, C_out, H_out, W_out)
// Overlap multiple convolutions
auto f1 = async_conv2d(input, weight1, bias1, 1, 1);
auto f2 = async_conv2d(input, weight2, bias2, 2, 0);
auto f3 = async_conv2d(input, weight3, bias3, 1, 2);
// All execute concurrently on different streams
auto r1 = f1.wait();
auto r2 = f2.wait();
auto r3 = f3.wait();

auto tenzor::async_matmul ( const Tensor & a,
const Tensor & b )->Future< Tensor >

Asynchronous matrix multiplication.

Performs matrix multiplication without blocking the calling thread. For CPU, uses thread pool. For GPU, uses CUDA streams.

Parameters
aLeft matrix (..., M, K)
bRight matrix (..., K, N)
Returns
Future<Tensor> for result matrix (..., M, N)
// Non-blocking matmul
auto future = async_matmul(a, b);
// Do other work
process_data();
// Wait for result
Tensor result = future.wait();
