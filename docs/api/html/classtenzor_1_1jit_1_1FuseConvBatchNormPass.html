Detailed Description

Operator fusion pass - Conv2d + BatchNorm2d.

Fuses convolution and batch normalization into a single operation by folding the batch norm parameters into the conv weights and biases.

Formula:

y = gamma * (conv(x) - mean) / sqrt(var + eps) + beta
Can be rewritten as:
y = conv(x, w', b') where:
w' = gamma * w / sqrt(var + eps)
b' = gamma * (b - mean) / sqrt(var + eps) + beta
