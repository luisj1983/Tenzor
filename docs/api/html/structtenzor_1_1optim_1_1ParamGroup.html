Detailed Description

Parameter group with individual learning rate.

Allows different learning rates and weight decay for different parameter groups. Useful for transfer learning or fine-tuning specific layers.

// Different learning rates for different layers
ParamGroup group1{backbone_params, 0.001, 0.0001};
ParamGroup group2{head_params, 0.01, 0.0001};
