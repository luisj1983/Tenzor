Detailed Description

Neural network activation functions and layers.

This file provides a comprehensive set of activation functions commonly used in deep learning, including both module-based (stateful) and functional (stateless) implementations. Activation functions introduce non-linearity into neural networks, enabling them to learn complex patterns.
