Detailed Description

Mean reduction gradient function.

Implements forward and backward for mean reduction operation.

Forward: y = mean(x, dim, keepdim) Backward: dL/dx = broadcast(dL/dy / count, original_shape)

Note
Gradient is divided by element count then broadcast to original shape.
