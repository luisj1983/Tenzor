Detailed Description

RAII context manager for compute region.

ComputeContext ensures that specified tensors are on GPU during the scope and automatically offloaded when the scope exits. Useful for manual control over specific tensor lifetimes.

Tensor param1 = get_offloaded_param();
Tensor param2 = get_offloaded_param();
{
ComputeContext ctx({&param1, &param2});
// Parameters are on GPU here
auto result = compute(param1, param2);
} // Parameters automatically offloaded to CPU
