Detailed Description

Device (GPU) memory storage managed by backend.

Manages device-side memory (CUDA, ROCm, OneAPI) through backend abstractions. Memory allocation and deallocation are delegated to the appropriate backend implementation.

Unlike CPUStorage, this class does not directly manage memory but coordinates with the backend system for proper lifecycle management.

Backend* backend = get_cuda_backend();
void* device_ptr = backend->allocate(1024);
auto storage = std::make_unique<DeviceStorage>(
device_ptr, 1024, Device::cuda(0), backend
);
