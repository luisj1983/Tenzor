Detailed Description

Represents the shape (dimensions) of a tensor.

Encapsulates tensor dimensions and provides utilities for shape manipulation, element counting, and comparison. Dimensions are stored as signed 64-bit integers to support negative indexing.

Shape shape({2, 3, 4}); // 3D tensor: 2x3x4
auto total_elements = shape.numel(); // Returns 24
