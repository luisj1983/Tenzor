Detailed Description

Fused kernel operations for reduced kernel launch overhead.

Provides optimized fused operations that combine multiple elementwise operations into single kernels, reducing memory bandwidth and kernel launch overhead. Targets 1.5-3x speedup over unfused operations.

Fusion patterns implemented:

  • Linear + ReLU: Fused fully connected layer with activation
  • Conv2D + ReLU: Fused convolution with activation
  • BatchNorm + ReLU: Fused normalization with activation
  • Softmax + CrossEntropy: Fused activation and loss computation
