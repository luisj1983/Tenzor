Detailed Description

Simple data loader for batch iteration.

Provides iterator interface for training/validation data batches. Supports both input-target pairs for supervised learning.

std::vector<std::pair<Tensor, Tensor>> data = {...};
DataLoader loader(data, 32); // Batch size 32
for (auto [inputs, targets] : loader) {
auto loss = model.train_step(inputs, targets);
}
