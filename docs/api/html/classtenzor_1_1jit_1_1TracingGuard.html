Detailed Description

RAII guard for tracing scope.

Automatically starts tracing on construction and stops on destruction. Ensures tracing is properly cleaned up even if exceptions occur.

{
TracingGuard guard;
Variable output = model(input);
auto graph = guard.get_graph({input}, {output});
}
