Detailed Description

Lightweight spin lock for short critical sections.

Spin lock that actively spins (busy-waits) until lock is acquired. Suitable for protecting very short critical sections where blocking would be more expensive than spinning.

When to Use:

  • Critical sections < 100 CPU cycles
  • Low contention scenarios
  • Real-time requirements

When NOT to Use:

  • Long critical sections (use std::mutex)
  • High contention (causes CPU waste)
  • I/O operations in critical section
Thread Safety
Thread-safe
SpinLock lock;
// ... in thread:
lock.lock();
// Critical section
lock.unlock();
