# Code of Conduct

Tenzor follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept constructive feedback, and prefer technical arguments over personal ones. Harassment, personal attacks, and discriminatory behavior are not tolerated in issues, pull requests, discussions, or any other project space.

## Reporting

If you experience or witness behavior that violates this code, please open a private report by emailing the maintainer at `lee.morton@gmail.com`. Reports will be handled confidentially and in good faith. The maintainer may warn, temporarily restrict, or permanently ban contributors whose behavior is judged to violate this code, depending on severity.

## Scope

This code applies to all project spaces — the GitHub repository (issues, pull requests, discussions, code review), and any official communication channel — and to behavior outside those spaces when it materially affects the project or its contributors.
